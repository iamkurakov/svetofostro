# Рецепты Светофора

Подбор рецептов под товары магазина и корзина рецептов со списком продуктов в граммах.

Сайт — один файл `index.html`. Работает без сервера, без сборки и без нейросети.

## Публикация на GitHub Pages

1. Положите `index.html` и `README.md` в корень репозитория.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Как пользоваться

1. Выберите товар в поиске или в карточках по категориям (по умолчанию — «Мясник Лёня»).
2. В карточке рецепта: «Состав и готовка» — раскрыть, «На съёмку» — сохранить в корзину.
3. «Корзина рецептов» → «Импорт продуктов» — окно с продуктами и граммами для покупки.

Корзина хранится в браузере (отдельно на каждом устройстве). Граммы для штучных продуктов (яйца, овощи, ломтики хлеба) рассчитаны по среднему весу и отмечены знаком ≈.
